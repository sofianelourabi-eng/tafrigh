# Tafrigh — installation

## 1. Mettre l'application en ligne (une seule fois, 10 minutes)
1. Créez un compte gratuit sur github.com.
2. Bouton « New » (nouveau dépôt) → nom : `tafrigh` → cochez **Public** → « Create repository ».
3. Cliquez sur « uploading an existing file », puis glissez **les fichiers** du dossier (pas le dossier lui-même) → « Commit changes ».
4. Onglet « Settings » → « Pages » → Source : « Deploy from a branch » → branche `main`, dossier `/ (root)` → « Save ».
5. Après 1 à 2 minutes, votre application est à l'adresse : `https://VOTRE-PSEUDO.github.io/tafrigh/`

## 2. Installer sur l'Android
1. Ouvrez l'adresse dans **Chrome**.
2. Menu ⋮ → « Installer l'application » (ou « Ajouter à l'écran d'accueil »).
3. Ouvrez Tafrigh depuis l'icône, choisissez « Rapide » ou « Précis », touchez **Préparer hors ligne** (en Wi-Fi).

## 3. Installer sur le Mac
1. Ouvrez l'adresse dans **Chrome** (recommandé : seul Chrome permet le modèle « Très précis »).
2. Icône d'installation à droite de la barre d'adresse → « Installer ».
3. Choisissez le modèle, puis **Préparer hors ligne**.

## 4. Vérifier le hors ligne
Mettez l'appareil en mode avion et ouvrez Tafrigh : la pastille indique « Hors ligne » et la transcription fonctionne.

## Bon à savoir
- Chaque modèle se télécharge une fois par appareil ; « ✓ téléchargé » s'affiche ensuite dans la liste.
- Sur le téléphone, découpez les enregistrements de plus de 40 minutes environ (mémoire limitée).
- Si vous effacez les données de Chrome, il faudra refaire « Préparer hors ligne ».
